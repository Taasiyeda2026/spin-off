# רקעי פוסטרים

מוסיפים, מחליפים או מסירים קובצי WebP לאורך בתיקייה `poster-backgrounds/webp/` וממזגים ל־main. תהליך GitHub Actions מייצר את הקטלוג והתמונות הממוזערות ופורס את האתר. אין מגבלת כמות ואין צורך לערוך JavaScript או HTML. שמות הקבצים הם מזהים קבועים; מיון השמות מספרי (למשל bg2 לפני bg10).

כל תמונה מקבלת כתובת קבועה לפי SHA-256. שינוי התמונה יוצר גרסה חדשה ורענון כתובת הקטלוג. הגלריה והפוסטר משתמשים באותה גרסה. התמונות הממוזערות נוצרות רק מתמונת ה־WebP.

פוסטרים שומרים גם `bgId` וגם `bgVersion`. החלפת קובץ אינה משנה את הרקע של פוסטר קיים; אפשר לבחור במכוון את הגרסה החדשה בגלריה. הסרת מקור מסתירה אותו מבחירות חדשות, אך פוסטר ששמר אותו ממשיך לטעון את הגרסה המקורית. כל הגרסאות נשמרות בפריסה מתוך היסטוריית Git, גם ללא גישה למסד הנתונים. לכן חובה `fetch-depth: 0` בתהליך הפריסה ואין למחוק את היסטוריית הקבצים.

`legacy-versions.json` מקבע את הרקעים של פוסטרים ישנים ששמרו מזהה בלבד. אין לשנות או למחוק את המיפויים הללו. רקע שלא ניתן לשחזר מציג שגיאה וחוסם PDF במקום לבחור רקע אחר בשקט.

בדיקה מקומית: `python tests/poster-background-build.test.py`.
הכנת הקטלוג להפעלה מקומית: `python scripts/build-poster-backgrounds.py`.

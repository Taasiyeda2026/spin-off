# SPIN-OFF

אתר הקורס **טכנולוגיות החלל** של תעשיידע.

האתר בנוי כאתר סטטי פשוט ב־HTML/CSS ומפורסם באמצעות GitHub Pages.

## עקרונות האתר

- אתר פשוט וקל לתפעול, ללא מערכת מורכבת וללא מסד נתונים.
- התאמה מלאה לדסקטופ, טאבלט ומובייל.
- RTL מלא לעברית.
- עיצוב ראשי המבוסס על תמונת החלל `images/home-bg.png`.
- כפתורי ניווט קטנים וקומפקטיים — לא כפתורים רחבים מקצה לקצה.
- תוכן עתידי יישב בתוך מעטפת ברוחב מוגבל כדי למנוע פריסה "מרוחה" במסכים רחבים.
- עמודי תוכן שיועדו להדפסה ייבנו כ־HTML אמיתי ויוכלו להפיק PDF אמיתי בגודל A4 — לא צילום או תמונה של העמוד.

## דף הבית

`index.html` הוא מסך הכניסה והניווט הראשי.

בדסקטופ הכפתורים מוצגים בגריד קומפקטי של 3×2 מעל תמונת הרקע.
בטאבלט ובמובייל התמונה נשמרת ביחס המקורי בחלק העליון, והכפתורים מסתדרים מתחתיה בצורה קומפקטית ונוחה למגע.

### הפעלת כפתור ניווט

כל כפתור נמצא בתוך `<nav class="home-nav">` ב־`index.html`.

כדי להפוך כפתור "בקרוב" לכפתור פעיל:

1. מחליפים את הטקסט `בקרוב` בשם העמוד.
2. משנים את `href` לנתיב העמוד, לדוגמה: `pages/lesson-01.html`.
3. מסירים את המחלקה `is-coming`.
4. מסירים את `aria-disabled="true"` ואת `tabindex="-1"`.

## עמודים פנימיים

לעמוד תוכן רגיל מומלץ להשתמש במעטפת:

```html
<main class="content-shell">
  ...
</main>
```

כך התוכן נשאר מרוכז ולא נמתח לכל רוחב המסך.

## עמודי A4 והפקת PDF

ב־`style.css` קיימת כבר תשתית למחלקה `a4-page` ולהדפסה בגודל A4.

עמוד שמיועד גם להדפסה יכול להיבנות כך:

```html
<main class="content-shell">
  <article class="a4-page">
    ...תוכן HTML אמיתי...
  </article>
</main>
```

בעת הדפסה מוגדר `@page` בגודל A4. טקסט, טבלאות ואלמנטים יישארו תוכן אמיתי ב־PDF ולא יהפכו לתמונה.

## קישורים יחסיים

מהעמוד הראשי:

```html
<link rel="stylesheet" href="style.css">
<img src="images/example.png" alt="">
```

מתוך עמוד בתיקיית `pages/`:

```html
<link rel="stylesheet" href="../style.css">
<img src="../images/example.png" alt="">
```
